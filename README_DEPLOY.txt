DETECOR X — PythonAnywhere

1. Загрузите ZIP в Files на PythonAnywhere и распакуйте в /home/ВАШ_ЛОГИН/detecor-x.
2. В Bash: cd ~/detecor-x && python3 -m pip install --user -r requirements.txt
3. Сгенерируйте хеш пароля в Bash:
   python3 -c "from werkzeug.security import generate_password_hash; import getpass; print(generate_password_hash(getpass.getpass('Пароль: ')))"
4. PythonAnywhere → Web → Add a new web app → Manual configuration → Python 3.x.
5. В WSGI configuration file (Web → Code) задайте:
   import os, sys
   path = '/home/ВАШ_ЛОГИН/detecor-x'
   if path not in sys.path: sys.path.insert(0,path)
   os.environ['DX_ADMIN_PASSWORD_HASH'] = 'ВСТАВЬТЕ_СВОЙ_ХЕШ'
   os.environ['DX_SECRET_KEY'] = 'ВСТАВЬТЕ_СЛУЧАЙНУЮ_СТРОКУ_ОТ_32_СИМВОЛОВ'
   os.environ['DX_HTTPS'] = '1'
   from app import app as application
6. Reload в разделе Web.
7. Сайт: https://ВАШ_ЛОГИН.pythonanywhere.com/
   Панель: https://ВАШ_ЛОГИН.pythonanywhere.com/control/login

ВАЖНО:
- Никогда не публикуйте пароль, хеш, SECRET_KEY, файлы WSGI или папку instance в GitHub.
- В PythonAnywhere НЕ задавайте static file mapping на корень проекта. Flask обслуживает только публичные файлы.
- Старый admin.html намеренно не публикуется.
- База: instance/training.sqlite3. Сделайте резервную копию через панель.
- Для бесплатного PythonAnywhere следите за сроком продления сайта в Web.
- После обучения новые посетители автоматически загружают обновлённую модель; уже открытые вкладки обновят её при возвращении на вкладку или после перезагрузки.
- Модель является эвристическим классификатором, а проценты не являются доказанной вероятностью авторства.

НОВОЕ В V2:
- В закрытом кабинете есть «Проверить без обучения», подробные признаки и процент.
- Кнопки меток показывают оценку до/после переобучения.
- Проверка не сохраняет пример; только кнопки «Написал человек/ИИ» обучают.
- Это логистическая модель на ручных признаках, не трансформер. Проценты не калиброваны.
- При локальном HTTP-запуске в PowerShell задайте $env:DX_HTTPS="0" до python app.py, иначе cookie сессии не работает.
- На PythonAnywhere используйте DX_HTTPS=1 и постоянный DX_SECRET_KEY.

=== V3: НАДЁЖНОСТЬ ОБУЧЕНИЯ ===
- Сервер хранит историю кандидатов в таблице versions (SQLite).
- Одинаковые наборы признаков не добавляются повторно. Это не полная проверка совпадения исходных текстов.
- Когда есть минимум 60 обучающих и 30 контрольных примеров и оба класса в обеих группах, используется стабильная отложенная выборка 20% (по хешу признаков).
- Публикация отклоняется, если F1 на контрольных данных ухудшается больше чем на 0.02 относительно предыдущей модели.
- До достижения порогов новая модель публикуется без подтверждённой проверки; не интерпретируйте это как гарантированное улучшение.
- Админ видит F1 и может вручную вернуть предыдущую опубликованную версию. Примеры при откате не удаляются.
- Важно: разделение по признакам и подбор модели на одной и той же контрольной выборке не заменяют независимого тестового набора. Для оценки качества выделите отдельные тексты, которые НИКОГДА не используются в обучении или выборе версий.
- Для нескольких параллельных рабочих процессов SQLite обеспечивает транзакции, но локальная блокировка TRAIN_LOCK действует только в одном процессе. Для высокой нагрузки нужен отдельный обучающий worker/очередь задач.
- Храните резервные копии instance/training.sqlite3 вне хостинга и не публикуйте instance, .env, ключи и бэкапы.
- Перед заменой старой версии сохраните копию instance/training.sqlite3. Не удаляйте instance при распаковке нового ZIP.
